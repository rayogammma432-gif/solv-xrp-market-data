SYNC

Conservar LAST_1M/5M/15M/1H/4H/1D_CLOSE y MARKET_UTC entre ANALIZA; leer solo TF nuevas salvo gap/inconsistencia/cambio de día relevante.

TRIGGERS

Un trigger confirma timing; nunca elimina anti-chase ni primer obstáculo.

MODO LIVE V3.4
LONG = SHADOW/RESEARCH ONLY. Nunca ACTIVE_LONG, nunca SIGNAL, riesgo 0%, aunque score/trigger/RR pasen. Registrar como CONDICIONAL con Live Mode=LONG_SHADOW y plan completo para evaluación forward.
SHORT = SHORT_EXPERIMENTAL. Puede ACTIVE_SHORT solo si cumple motor base + Execution Gate=PASS + Thesis válida/no duplicada. No aumentar riesgo por score alto.
SCALP/PRIMARY SHORT mantienen riesgos actuales; esta versión no convierte resultados históricos en permiso de sobreoperar.

EXECUTION GATE SHORT
PASS exige TODOS:
E1 trigger del motor=YES.
E2 anti-chase PASS: Entry está en nivel/retest razonable y el primer obstáculo deja RR real>=1.5.
E3 geometría válida: SHORT requiere Stop > Entry > TP1 >= TP2.
E4 retest/aceptación/rechazo posterior demostrado cuando el setup nació de ruptura directa; un nuevo trigger dentro de la misma extensión no basta.
E5 no existe contradicción estructural mayor ni BTC FUERTEMENTE CONTRARIO.
Si falta E1/E2/E4 => WAIT. Si geometría inválida, tesis duplicada/expirada o contradicción mayor => BLOCK. Solo PASS puede crear ACTIVE_SHORT/SIGNAL.

ANTI-CHASE
Evaluar distancia a nivel, EMA20, VWAP, ATR15m y primer obstáculo. Si precio ya se alejó del nivel o llegó cerca de soporte/objetivo, WAIT_RETEST. No mover Entry al mercado, no ampliar Stop y no usar TP lejano artificial para fabricar RR. Extension Warning en dirección SHORT => WAIT_RETEST salvo retest cerrado posterior y defendido.

THESIS ID / DEDUP / EXPIRY
Cada plan con niveles debe tener Thesis ID estable:
<MOTOR>|<DIR>|<SETUP_ANCHOR>|<ENTRY_ZONE>|<STOP_LEVEL>
Antes de ACTIVE/SIGNAL revisar SIGNALS OPEN + USER_TRADES OPEN + ANALYSES recientes. Misma dirección/motor y estructura/nivel equivalente = misma tesis; reutilizar ID, no crear otra señal por pequeñas variaciones de precio.
PRIMARY pre-entry expira a las 2h desde creación o antes por invalidación estructural. SCALP pre-entry expira a los 45m o antes por invalidación. Si expira: Thesis Lifecycle=EXPIRED, Execution Gate=BLOCK; nueva tesis requiere nuevo trigger cerrado y nuevo ancla estructural.

TP1 1R SHADOW — SOLV_TP1_1R_R1
Nunca sustituye TP1/TP2 productivos ni cambia ACTIVE/riesgo.
Si Entry/Stop son válidos:
LONG shadow target1R = Entry + ABS(Entry-Stop).
SHORT target1R = Entry - ABS(Entry-Stop).
Registrar target y variante. Tracker determina cronológicamente 1R vs STOP con velas 1m. No usar MFE/MAE para inferir orden. Resultado shadow no modifica la operación live.

ATR STOP STRESS — SHADOW
struct=ABS(Entry-Stop); floor=0.50*ATR15m; stress=MAX(struct,floor); stressRR=ABS(TP1-Entry)/stress.
PASS si >=1.5; FAIL si <1.5; N/A si faltan datos. No cambia gate/score/stop/riesgo en SOLV V3.4; solo investigación.
